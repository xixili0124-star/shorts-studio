# PC 편집 화면

기준: `0d2f41b` · 작업 브랜치 `codex/desktop-redesign-20260906`.
기존 편집 엔진 위에 PC 전용 작업 화면과 모바일 공통 개선을 적용했습니다.

## 작업의 목적에 따라 정리

- 왼쪽: 파일 / 자막 / 소리 / 디자인 / 트래킹. 기존 기능을 작업별 하위 메뉴로 연결합니다.
- 자막: 자막 / 자동자막 / 자막 목록. 직접 추가와 스타일은 첫 탭, 자동 인식은 두 번째 탭입니다. 처리 위치·동의·오류 안내는 유지합니다.
- 소리: 효과음 / AI TTS / 무음 컷. 트래킹 상위 메뉴는 모자이크 / 크롭을 고르는 화면만 엽니다. 선택한 영상이 있으면 사용자가 누른 추적 하위 탭에서 해당 기능창을 엽니다. 마지막 사용 항목을 기억하더라도 상위 메뉴 재방문만으로 기능창을 열지 않습니다.
- 중앙: 선택한 클립의 기본 / 꾸미기 / 움직임 / 세부. 선택하지 않았거나 속성을 닫으면 라이브러리가 남는 폭을 사용합니다. 같은 클립을 다시 선택하면 속성이 다시 열립니다.
- 오른쪽: 9:16 미리보기와 재생 조작을 위부터 아래까지 고정합니다. 타임라인 높이와 독립적이며 원래 캔버스·렌더러·화면 편집 손잡이를 사용합니다.
- 타임라인: 분할·복제·삭제·스냅은 트랙 칸과 메뉴 패널을 침범하지 않도록 오른쪽에 놓고 설정 복사·붙여넣기·당겨 삭제는 더보기에 둡니다. 상단 트랙 + 메뉴는 제거하고 각 행의 +는 유지합니다.
- 프로젝트 저장·열기·도움말은 프로젝트 메뉴, 영상 내보내기는 내보내기 버튼입니다.
- 트랙 칸은 184px, T/G/V/A/V 배지는 모두 24×24px입니다. 타임라인은 왼쪽 작업 공간 아래에 놓으며 오른쪽 미리보기 영역을 침범하지 않습니다. 도구 줄은 00:00과 같은 시작선에 정렬하고 좁은 영역에서는 아이콘으로 표시합니다.

## 경계로 크기 조절

- 미리보기의 왼쪽 세로 경계를 끌면 미리보기와 왼쪽 작업 공간 사이의 폭이 바뀝니다. 작게 보기 버튼은 200px로 줄이고 이전 폭으로 복원합니다.
- 라이브러리와 속성 사이의 세로 경계를 끌면 두 영역의 폭이 바뀝니다. 미리보기와 타임라인의 폭은 바뀌지 않습니다.
- 타임라인 위의 가로 경계를 끌면 왼쪽 작업 공간과 타임라인의 높이가 바뀝니다. 세로 미리보기의 위치와 크기는 유지됩니다.
- 세로 경계는 좌우, 가로 경계는 상하 크기 조절 커서로 표시합니다. 키보드 화살표·Home·End도 지원하며 저장 값은 브라우저에 보관합니다. 창이 작아지면 조작 가능한 최소 폭 안으로 보정하고 원래 선호 크기를 유지합니다.
- 900px 이하 PC 창의 속성은 왼쪽 위 작업 영역 안에만 겹쳐 엽니다. 내비게이션·타임라인·미리보기를 덮지 않습니다. 모바일로 전환하면 PC의 폭 설정과 경계 조절은 해제합니다.

## 추가된 사용 흐름

- 내 목소리: 녹음 / 파일 업로드로 시작하고 목록에서 선택·개별 삭제합니다. 최대 3개이며 기존 등록은 보존합니다. 준비된 PC 엔진은 재사용하고, 연결 프로그램이 있지만 음성 모델이 없는 경우 동의 후 고정 설치 작업의 실제 상태를 확인합니다. 준비 대기를 닫아도 이미 시작한 다운로드는 PC에서 계속됩니다.
- PC 연결 프로그램 자체가 없는 새 기기는 브라우저 보안상 받은 설치 파일을 처음 한 번 사용자가 실행해야 합니다. 웹페이지만으로 OS 프로그램을 자동 설치한다고 안내하지 않습니다.
- 퀵포맷: 이름 입력 없이 현재 문구·여백·위치·폰트·크기·색을 저장합니다. 각 저장 행은 체크(적용)·X(삭제)·연필(이름 수정) 버튼을 제공합니다. 이름 수정은 Enter/저장으로 확정, Esc/취소로 되돌리고 저장된 스타일은 변경하지 않습니다. 이 브라우저에 최대 20개 보관합니다.
- 효과음: 기존 사용자 제공 37개 파일은 유지하고 클릭·촬영, 알림·완료, 오류·의문, 등장·상승, 타격·폭발, 코믹·리액션, 드럼·긴장, 게임·무기, 금전으로 분류했습니다. 재배포 권리 확인 상태는 CREDITS.md를 따릅니다.
- 샘플: 말하는 인물·고양이·물결의 실제 CC0 동영상과 원음을 사용합니다. 고양이 원음의 불연속 시각을 보정해 정확히 10초로 맞췄습니다. 기존 서울 사진 3개와 합성 예시 음악 코드는 제거했습니다. 사용자 프로젝트의 기존 미디어는 삭제하지 않습니다. 프로젝트 메뉴 → 동영상 샘플 열기로 명시적으로 바꿀 수 있습니다.
- 오래된 자동 저장에서 프로젝트 이름과 파일 메타데이터가 서울 예시이며 타임라인에 외부 미디어를 사용하지 않았다면 영상 예시로 교체하고 새 자동 저장을 완료합니다. 라이브러리에만 남은 사용자 파일은 보존합니다. 이름을 바꾸거나 외부 파일을 타임라인에 사용한 프로젝트는 자동 교체하지 않습니다.
- 로고: S 대신 이미지 생성 도구로 만든 둥근 번개 심벌입니다. 생성 정보는 `public/brand/README.md`에 기록했습니다.

## 보존 조건

`DesktopStudio`는 기존 입력·버튼·미리보기·타임라인 노드를 사용합니다. 영상 렌더러·내보내기·AI 모델은 교체하지 않습니다. 음성 준비 API는 로컬/승인된 연결 및 명시적 다운로드 동의를 요구하며 임의 실행 명령을 받지 않습니다. 새 앱 의존성과 빌드 단계는 없습니다.

PC 스타일과 속성 필터는 `body.desktop-ui:not(.mobile-ui)`에만 적용합니다. 속성 섹션을 감싸거나 재배치하지 않으므로 모바일의 기존 하위 작업 필터가 유지됩니다. PC와 모바일 모드 사이에서도 하나의 캔버스·타임라인을 사용합니다.

새 속성이 추가되면 알 수 없는 섹션은 세부 탭으로 연결됩니다. 섹션 밖의 글꼴 이용 조건·설정 복사·삭제도 세부 탭에서 접근할 수 있습니다.

## 검증

- Node 검사 422개 통과. 모든 JS 문법 검사 통과. 기존 다른 작업 폴더의 변경 없음 확인.
- `tests/browser-desktop.html`: 16개 통과. 탐색·트랙 이름/배지·자막 분리·자막 수정·키프레임 탭 유지·메뉴·저장 퀵포맷 복원·PC↔모바일 전환·되돌리기에 더해, 패널별 실제 치수와 경계 조절·닫기·재선택·작은 창의 팝업을 검사합니다. 선택한 동영상이 있어도 상위 트래킹과 재방문은 창을 자동으로 열지 않고, 모자이크·크롭 하위 탭만 해당 창을 여는지 확인합니다. 자동 검사 중에는 테스트 입력에 실제 키 입력이 섞이지 않도록 검수 iframe 안의 물리 키 입력만 차단합니다.
- 이번 레이아웃 수동 확인: 1024×900, 1366×768, 900×800과 실제 사용자 창. 실제 포인터로 영상 시작을 0.00→0.70초로 트림했을 때 연결 원음도 함께 바뀌고, 실행 취소로 둘 다 복원됐습니다. 속성 경계를 실제 마우스로 300→340px 조절했을 때 미리보기는 353px를 유지했고 Home으로 300px를 복원했습니다.
- 실제 사용자 창에서 오른쪽 미리보기 영역은 상단 64px부터 하단 985.6px까지 유지하며, 캔버스 316×561.8px의 9:16 비율을 확인했습니다. 크기는 창과 저장한 폭에 따라 달라집니다.
- `tests/browser-mobile.html`: 모바일 타임라인 합성 터치·전체 트랙 배치·메뉴 연결 검사 14개 통과.
- 수동 브라우저: 1440×1000, 1366×768, 960×800. 미리보기 재생·정지와 내보내기 설정 화면 연결 확인.
- 이번 피드백 수동 브라우저: 새 동영상 3개와 원음 3개의 분리·미리보기 재생, 모자이크·크롭 기능창 직접 연결, 기존 PC 목소리 2개 인식·목록 표시 확인. 실제 사용자 목소리를 추가·삭제하거나 새로 합성하지 않았습니다.
- Python 관련 검사: PC 브리지 44개, 서버 56개, 설치 34개 통과. PC 지원 다운로드 패키지 재생성 완료.
- 실제 휴대전화의 터치 하드웨어·OS 및 전체 AI 모델 실행은 이번 UI 검증 범위가 아닙니다. 새 영상 인코딩 결과를 별도로 생성하지는 않았습니다.

브라우저 검사는 테스트 HTML을 `public/_test/`에 복사하고 정적 서버에서 열어 실행합니다. **개인 작업과 다른 포트/브라우저 프로필을 사용하세요.** 앱의 빈 테스트 프로젝트를 사용하므로 해당 검수 주소의 자동 저장 내용이 바뀔 수 있습니다. `_test/`는 Git에서 제외됩니다.
