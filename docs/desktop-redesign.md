# PC 편집 화면 시안

기준: `0d2f41b` · 별도 브랜치 `codex/desktop-redesign-20260906`.
운영 main에 합치거나 배포하지 않은 검토용 변경입니다.

## 작업의 목적에 따라 정리

- 왼쪽: 파일 / 자막 / 소리 / 디자인 / 도구. 기존 9개 라이브러리 화면을 하위 메뉴로 연결합니다.
- 자막: 만들기 / 스타일 / 자막 목록. 자동 인식의 처리 위치·동의·오류 안내는 유지합니다.
- 오른쪽: 선택한 클립의 기본 / 꾸미기 / 움직임 / 세부. 없는 속성의 탭은 표시하지 않습니다.
- 타임라인: 분할·복제·삭제·스냅은 상시 표시, 설정 복사·붙여넣기·당겨 삭제는 더보기에 둡니다. 트랙 추가는 + 메뉴와 기존 각 행의 + 모두 제공합니다.
- 프로젝트 저장·열기·도움말은 프로젝트 메뉴, 영상 내보내기는 완성하기 버튼입니다.

## 보존 조건

`DesktopStudio`는 기존 입력·버튼·미리보기·타임라인 노드를 사용합니다. 편집 상태, 영상 렌더러, 내보내기, AI 모델과 네트워크 정책은 변경하지 않습니다. 새 의존성과 빌드 단계도 없습니다.

PC 스타일과 속성 필터는 `body.desktop-ui:not(.mobile-ui)`에만 적용합니다. 속성 섹션을 감싸거나 재배치하지 않으므로 모바일의 기존 하위 작업 필터가 유지됩니다. PC와 모바일 모드 사이에서도 하나의 캔버스·타임라인을 사용합니다.

새 속성이 추가되면 알 수 없는 섹션은 세부 탭으로 연결됩니다. 섹션 밖의 글꼴 이용 조건·설정 복사·삭제도 세부 탭에서 접근할 수 있습니다.

## 검증

- Node 검사 388개 통과. 모든 JS 문법 검사 통과.
- `tests/browser-desktop.html`: 실제 앱 DOM 연결 7개 통과. 탐색·자막 생성과 수정·키프레임 탭 유지·메뉴·PC↔모바일 전환·되돌리기.
- `tests/browser-mobile.html`: 기존 모바일 타임라인 합성 터치 검사 11개 통과.
- 수동 브라우저: 1440×1000, 1366×768, 960×800. 미리보기 재생·정지와 내보내기 설정 화면 연결 확인.
- 로고 SVG 중심과 배경 상자 중심 차이: 가로 0px, 세로 0px.
- 실제 휴대전화의 터치 하드웨어·OS 및 전체 AI 모델 실행은 이번 UI 검증 범위가 아닙니다. 새 영상 인코딩 결과를 별도로 생성하지는 않았습니다.

브라우저 검사는 테스트 HTML을 `public/_test/`에 복사하고 정적 서버에서 열어 실행합니다. **개인 작업과 다른 포트/브라우저 프로필을 사용하세요.** 앱의 빈 테스트 프로젝트를 사용하므로 해당 검수 주소의 자동 저장 내용이 바뀔 수 있습니다. `_test/`는 Git에서 제외됩니다.
