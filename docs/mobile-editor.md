# 모바일 편집 화면

PC의 기존 화면과 편집 엔진을 유지하면서 모바일 배치와 입력 동작을 분리합니다.

## 화면

- 기본 자동 선택: 폭 760px 이하, 또는 터치 중심 기기의 폭 1100px 이하.
- 세로: 미리보기 → 선택 클립 작업 → 타임라인 → 하단 도구.
- 가로: 왼쪽 미리보기, 오른쪽 타임라인. 도구 패널도 오른쪽에서 열립니다.
- 라이브러리·속성·더보기는 같은 위치의 패널을 공유하며 하단 도구로 전환합니다.
- PC의 저장된 타임라인 높이를 모바일 배치로 덮어쓰지 않습니다.
- 검수 주소 옵션 `?ui=mobile` / `?ui=desktop`은 화면에만 적용하며 저장하지 않습니다.

## 타임라인 조작

- 탭: 클립·공백·전환 선택. 빈 배경 또는 눈금을 탭하면 재생 위치 이동.
- 쓸기: 가로·세로 스크롤.
- 클립을 300ms 길게 누르고 이동: 기존 이동·교환·연결 클립 편집 사용.
- 길게 누르고 제자리에서 놓기: 클립 메뉴.
- 선택 클립 양끝 손잡이: 길이 조절.
- 두 손가락: 손가락 중점의 시각을 유지하며 확대·축소. 진행 중 이동은 취소.
- ‘여러 선택’: 클립을 탭해 선택 추가·해제. 분할·삭제·설정 붙여넣기는 기존 묶음 명령을 사용.
- 더보기: 저장·열기·실행 취소·복제·설정 복사 및 붙여넣기·트랙 관리·스냅·반복 재생·안전영역.

## 경계

`mobile-studio.js`는 기존 앱 명령에 연결하는 화면 제어기입니다. 렌더러, 인코더, 프로젝트 형식, 자동자막/TTS/추적의 엔진 선택·동의·다운로드 정책을 복제하거나 변경하지 않습니다. `mobile.css`의 시각 규칙은 `body.mobile-ui`에만 적용합니다. 마우스 타임라인 동작도 그대로 둡니다.

## 검증

Node 검사: `tests/mobile-studio.test.mjs`, `tests/mobile-timeline-touch.test.mjs` 및 기존 전체 검사.

`tests/browser-mobile.html`을 로컬 정적 서버의 공개 디렉터리에 임시 복사하여 전체 검사를 실행할 수 있습니다. 실제 Timeline DOM·좌표 판정·이동/트림 명령을 사용하지만 포인터 이벤트와 캡처는 테스트용으로 모사합니다. 사용자 프로젝트나 자동 저장은 불러오지 않습니다. 검사 후 공개 디렉터리의 복사본은 제거합니다.

실제 휴대전화에서 별도 확인할 항목: iOS Safari/Android Chrome의 터치 캡처, 주소창·가상 키보드·회전, 파일 선택, 내보내기/다운로드, 기기별 메모리 한계. 데스크톱의 모바일 화면 크기 검사와 실제 기기 검증은 구분합니다.
