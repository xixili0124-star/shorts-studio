한국어 자동자막,
PC에서는 Turbo로.

Whisper large-v3-turbo를 이 PC에 한 번 준비하고, 같은 편집기의 자막 패널에서 사용하세요. 기존 모바일용 Whisper Tiny와 내 목소리 TTS는 그대로 유지합니다.

처음 한 번 · Windows PC 준비

  1. 최신 실험판 폴더에서 setup-pc-asr.cmd를 실행하세요.
    설치 도구를 실행할 Python 3.10 이상과 Windows 64비트가 필요합니다. 전용 Python 3.11 환경은 자동으로 준비합니다.
  2. 모델·실행 환경 다운로드에 동의하세요.
    모델 약 1.62GB와 별도 실행 환경을 받습니다. CUDA 라이브러리 다운로드만 약 570MB가 추가되며, 설치·캐시를 위해 디스크 여유 공간 8GB 이상을 확보해 주세요. Vox·GPT-SoVITS 환경에는 설치하지 않습니다.
  3. 편집기를 실행하세요.
    기본 편집기는 start-studio.cmd, 내 목소리 TTS도 함께 쓸 때는 start-pc-voice.cmd를 실행합니다. 이전 실행기가 켜져 있다면 프로젝트를 저장한 뒤 종료하고 최신 실행기로 다시 시작하세요.
  4. 자막 → 자동자막 엔진에서 PC Turbo 연결을 확인하세요.
    영상·오디오 클립을 선택하거나 전체 타임라인을 고르고 실행합니다. 결과를 검수한 뒤 새 자막 트랙에 추가하며, 기존 자막은 지우지 않습니다.

기본 설치는 NVIDIA CUDA GPU용입니다. GPU 없는 PC는 setup-pc-asr.cmd --device cpu로 별도 선택할 수 있지만 처리 시간이 길어질 수 있습니다. GPU 오류가 나도 CPU나 외부 유료 API로 몰래 전환하지 않습니다.

공유 웹사이트에서 다른 PC의 엔진을 원격으로 호출하지 않습니다. 완성한 자막과 음성은 .shorts 프로젝트로 다른 기기에 옮겨 편집할 수 있습니다.

TTS와 GPU 메모리는 어떻게 쓰나요?

같은 PC 음성 엔진의 TTS와 자동자막은 순서대로 처리합니다. GPU 여유가 있으면 Vox 모델을 유지하고, 부족할 때만 GPU에서 내려 공간을 확보합니다. 다음 TTS 요청에서 다시 불러오므로 재다운로드는 필요하지 않습니다.

Turbo는 자막 작업이 끝나면 실행 프로세스가 종료되어 GPU 메모리가 반환됩니다. 취소 버튼도 실제 자막 작업을 중단합니다. 매번 로컬 모델을 불러오는 준비 시간이 포함됩니다.

다른 편집기·게임·AI가 GPU 메모리를 사용하면 실행에 실패할 수 있습니다. 작업 종료 여부가 불확실하다는 안내가 나오면 프로젝트를 저장하고 PC 실행기를 다시 시작해 주세요. 앱은 다른 프로그램을 강제로 종료하지 않습니다.

결과는 꼭 한 번 확인하세요

숫자·사람 이름·빠른 말·배경음이 섞인 음성은 틀릴 수 있습니다. 단어별 시각이 없지만 실제 발화 구간 시각이 있는 경우에는 문장 전체를 한 자막으로 보존하고 경고합니다. 단어 시간을 임의로 나누어 만들지 않습니다.

전체 인식은 영상 소리와 보이스 트랙을 대상으로 하며 배경음악은 제외합니다. 일반 오디오 트랙의 말소리를 인식하려면 해당 클립을 선택해서 실행해 주세요.

추가 학습·화자 분리·TTS 원고 강제 정렬은 이번 Turbo 연결에 포함하지 않습니다. 한국어 받아쓰기와 기존 자막 검수·편집 흐름을 사용합니다.

개인 오디오와 설치 파일

모델·실행환경은 PC에만 설치하며 Git과 배포 ZIP에 포함하지 않습니다. 인식용 PCM은 브라우저에서 같은 PC 서버로 전달하고 파일로 따로 저장하지 않습니다. 결과는 작업 검수용으로 서버 메모리에 임시 보관합니다.

추론 중 모델 자동 다운로드와 Python 네트워크 요청을 차단합니다. 설치 단계에서만 공개 모델·패키지를 내려받으며 API 키가 필요하지 않습니다.
