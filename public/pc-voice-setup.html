모바일의 처리 시간·메모리·내보내기 지원은 기기와 브라우저에 따라 달라집니다. 모든 휴대폰에서 같은 속도와 기능을 보장하지는 않습니다.

처음 한 번 · Windows PC 준비

현재 자동 설치 도구는 Windows 64비트용입니다. 시작 도구를 실행할 Python 3.10 이상과 10GB 이상의 여유 공간이 필요합니다. 전용 Python 3.11과 모델은 편집기와 분리된 폴더에 설치합니다.

  1. 현재 작업부터 저장

    지금 편집 중이라면 .shorts 프로젝트 저장으로 소재와 편집 내용을 보관하세요. 브라우저 주소가 바뀌면 자동 저장 공간도 달라집니다.

  2. 실험 브랜치 내려받기

    압축을 완전히 풀어 주세요. 원본 운영 버전과 별도 폴더에 두면 됩니다. GitHub 로그인이 필요할 수 있습니다.

    PC용 실험판 ZIP 받기

  3. 음성 엔진 설치

    폴더의 setup-pc-voice.cmd를 실행하고 다운로드 안내에 동의하세요. 모델·발음 자료 약 1.5GB, 실행 환경은 별도로 수 GB를 받습니다. 전역 Python을 바꾸지 않습니다.

    기본은 NVIDIA GPU용 CUDA 설치입니다. NVIDIA GPU가 없으면 터미널에서 setup-pc-voice.cmd --device cpu로 설치할 수 있지만 생성이 오래 걸릴 수 있습니다. 설치 중에 참고 녹음은 업로드하지 않습니다.

  4. PC용 편집기 시작

    start-pc-voice.cmd를 실행하고 창에 표시되는 로컬 편집기 주소를 여세요. 엔진이 준비되면 AI 음성 → 실행 방식 → PC 확장 · 내 목소리에서 연결을 확인합니다.

    편집하는 동안 시작 창을 열어 두세요. 기존 8787 포트가 사용 중이면 기존 작업을 저장한 뒤 서버를 종료하거나, start-pc-voice.cmd --port 8788로 따로 실행하세요. 실행기는 다른 프로그램을 강제로 종료하지 않습니다.

편집기 안에서 내 목소리 만들기

  1. 내 목소리 등록

    조용한 곳에서 평소 말투로 3~10초 녹음한 파일을 고르거나, 편집기에서 마이크로 녹음하세요. 마이크 녹음은 최대 9초에 자동 종료됩니다.

  2. 녹음에서 읽은 문장 입력

    참고 녹음의 내용과 문장을 정확히 맞춘 뒤 보관에 동의하고 등록하세요. 이 문장은 나중에 읽힐 새 원고와 별개입니다.

  3. 새 원고 생성·확인·추가

    등록한 목소리를 선택하고 새 원고를 입력해 내 목소리로 만들기를 누르세요. 들어보고 괜찮으면 보이스 트랙에 추가합니다. WAV 파일로도 저장할 수 있습니다.

GPT-SoVITS v2ProPlus가 짧은 녹음을 참고하는 방식입니다. 개인 모델을 학습하는 기능은 아직 포함하지 않습니다. 닮은 정도·한국어 발음·억양은 녹음과 문장에 따라 달라지며, 유료 서비스와 같은 품질을 보장하지 않습니다.

저장과 기기 이동

참고 녹음·읽은 문장은 PC의 .studio-local/voices에 따로 보관합니다. 소재함·자동 저장·.shorts 프로젝트·Git에 포함하지 않습니다. 원고와 참고 녹음은 외부 TTS 서비스에 보내지 않습니다.

PC에서 생성한 음성을 타임라인에 추가 → .shorts 저장 → 모바일에서 열기 순서로 이어서 작업하세요. 완성된 음성은 파일에 포함되지만 참고 목소리는 따라가지 않습니다. 다른 PC에서 같은 목소리를 다시 생성하려면 별도 등록이 필요합니다.

삭제·취소는 어떻게 동작하나요?

참고 음성 삭제는 PC에 보관한 녹음과 읽은 문장을 지웁니다. 이미 만든 WAV·프로젝트 사본은 유지됩니다. 엔진이 기억 중인 참조 정보는 엔진 종료 시 해제됩니다.

저장·삭제 창을 닫아도 이미 시작한 파일 작업은 완료될 수 있으므로 등록 목록을 확인하세요. 생성 중 취소는 결과 받기를 취소하며 GPU 작업은 잠시 계속될 수 있습니다. 응답 완료가 불확실하면 프로젝트를 저장하고 PC 엔진과 로컬 서버를 다시 실행하세요.

공유 웹주소에서 PC 엔진을 바로 켤 수 없나요?

공개 사이트나 휴대폰에서 이 PC의 엔진을 자동 호출하지 않습니다. PC의 로컬 편집기로 접속해 주세요. 외부 공개 주소·공유기 포트 개방·유료 API 키는 필요 없습니다.

본인 또는 사용 허락을 받은 목소리만 등록하세요. 다른 사람을 사칭하지 말고, 공유할 때 AI 생성 음성임을 알려 주세요.
